# Quickstart: 证件图片处理工具验证指南

**Feature**: image-tool | **Date**: 2026-08-12 (updated 2026-08-13)

## 前置条件

- Node.js ^20.19.0 || >=22.12.0
- 已安装依赖: `npm install`
- Chrome/Edge 浏览器（推荐）

## 启动开发环境

```bash
npm run dev
# 访问 http://localhost:5173/card
```

## 验证场景

### 场景 1: 单面证件 — 学历证加水印

1. 打开 `/card` 页面
2. 从类型下拉选择 **"学历证"**
3. 确认上传区显示 **1 个**上传框，标注"点击上传正面"
4. 在水印输入框输入 `仅供XX办理使用`
5. 点击上传框，选择一张学历证照片（JPG/PNG）
6. 在裁剪弹窗中：在空白处按下鼠标拖动绘制裁剪框，确认覆盖证件主体
7. 点击 **"确认裁剪"**
8. 确认预览区实时显示带半透明水印的效果，上传框显示 70% 尺寸缩略图
9. 点击左栏底部 **"导出图片"**
10. 确认浏览器下载一张 PNG 图片，水印正确叠加

**期望结果**: 下载的 PNG 图片中水印以平铺模式半透明覆盖证件，原图清晰度不降低。

### 场景 2: 双面证件 — 身份证正反面合并

1. 打开 `/card` 页面
2. 从类型下拉选择 **"身份证"**
3. 确认上传区显示 **2 个**上传框："正面（人像面）"和"反面（国徽面）"
4. 在水印输入框输入 `仅供办理银行业务`
5. 调整水印透明度为 50%，密度 70%，字号 20px
6. 点击正面框，上传身份证正面 → 在空白处拖动绘制裁剪框 → 确认
7. 点击反面框，上传身份证反面 → 同样方式裁剪 → 确认
8. 确认预览区显示正反面**上下合并**的带水印效果（每张占 A4 70% 宽，按 ID 比例 1.586）
9. 点击左栏底部 **"导出图片"**
10. 确认下载一张正反面合并的 PNG

**期望结果**: 合并图中正面在上、反面在下，水印居中覆盖整张图。

### 场景 3: 裁剪操作

1. 选择任意类型，上传一张图片
2. 在裁剪弹窗中：
   - **在 canvas 空白处按下鼠标拖动** → 绘制新裁剪框（自由比例，不锁定）
   - **拖动四角手柄** → 微调裁剪框大小
   - **点击裁剪框内部** → 也会触发绘制新裁剪框（不支持移动）
   - **鼠标拖出 canvas 边界** → 仍能继续追踪更新裁剪框（window 监听）
   - **鼠标滚轮缩放图片显示大小**（30%-300%）
   - 点击左旋/右旋按钮（每次旋转 90°）
   - 点击"重置"恢复默认裁剪框
   - 点击 overlay 空白区域 / X 按钮 / 按 ESC 键 → 关闭弹窗并清空该槽位
3. 点击"确认裁剪"
4. 上传框显示裁剪后缩略图（70% 尺寸）
5. 点击缩略图 → 重新打开裁剪弹窗，可重新裁剪

**期望结果**: 裁剪框自由绘制不锁定比例；四角手柄微调正常；鼠标超出边界仍能继续追踪；取消裁剪正确清空上传内容并关闭弹窗。

### 场景 4: 水印实时预览

1. 已完成图片裁剪
2. 在水印 4 行配置面板中修改各项参数：
   - 输入水印文字 → 预览立即更新
   - 拖动密度滑块 → 预览实时变化（密度高=间距小）
   - 拖动透明度滑块 → 预览实时变化
   - 修改字号 → 预览实时变化
   - 调整倾斜度（-45° ~ 45°）→ 预览实时变化
   - 修改水印颜色 → 预览实时变化

**期望结果**: 每次修改水印参数后，预览区在 200ms 内更新显示；水印文字按设定角度倾斜绘制。

### 场景 5: 重置与类型切换

1. 已上传图片、设好水印
2. 点击左栏底部 **"重置"** → 所有上传图片和水印清空
3. 重新选择类型、上传、加水印
4. 尝试切换证件类型 → 弹出确认对话框
5. 点击"取消" → 保持当前状态
6. 再次切换并点击"确认" → 上传框重置，水印保持不变

**期望结果**: 重置清空图片和水印；类型切换清空图片但保留水印。

### 场景 6: 国际化

1. 页面右上角点击语言切换按钮（中 ↔ EN）
2. 确认所有 UI 文案切换为对应语言：
   - 导航栏标签显示"证件"/"Card"
   - 类型下拉选项
   - 上传框标注
   - 水印配置标签
   - 按钮文字
   - Toast 提示
3. 切换回原语言，确认还原

**期望结果**: 中英文切换后无遗漏的硬编码文案。

### 场景 7: 深色模式

1. 切换主题为深色模式
2. 确认页面各区域正常显示：背景色、文字色、边框色、水印预览
3. 上传图片 → 裁剪弹窗在深色模式下正常
4. 导出图片（水印合成不受主题影响）

**期望结果**: 深色模式下所有 UI 区域正确使用 CSS 变量，水印导出结果不受主题影响。

### 场景 8: 布局验证

1. 打开页面，确认整体为**左右两栏布局**：左栏（280px，类型选择+上传+水印+操作按钮）/ 右栏（A4 纸预览）
2. 确认页面 padding 为 `80px 24px 48px`（与其他工具页一致，避开导航栏）
3. 确认左栏背景 `#f3f4f6`，右栏内层背景 `#f3f4f6`，A4 纸白色 + 阴影
4. 确认水印配置为**4 行纵向布局**
5. 确认 ActionBar 位于左栏底部（Reset 左、Export 右，靠左并排）
6. 确认预览区**无滚轮缩放**功能（已移除）

**期望结果**: 左右两栏布局紧凑；ActionBar 在左栏底部；预览区无缩放控件。
