# Feature Specification: 证件/卡证打印与水印预处理工具

**Feature Branch**: `001-image-tool`

**Created**: 2026-08-12

**Status**: Draft

**Input**: User description: "在 /card 路由下增加证件/卡证处理，正反面的数据进行合并到一张图中，然后进行打印与水印预处理功能"

**Updated**: 2026-08-13 — 路由从 `/image` 改为 `/card`，i18n 新增 `card` key（中文"证件"/英文"Card"）；裁剪改为自由绘制（不锁定比例、移除移动、window 监听拖动）；预览移除滚轮缩放；卡片按 ID 比例 1.586；ActionBar 移入左列底部；UploadSlot 缩略图 70% 尺寸；默认水印 opacity 0.5 / fontSize 20 / density 0.7。

## 页面布局说明

整个工具为**左右两栏布局**，仅裁剪操作用弹窗，无纵向滚动条：

```bash
┌──────────────────────────────────────────────────────────┐
│  顶部导航栏 (64px)                                        │
├───────────────────────┬──────────────────────────────────┤
│  左栏 (280px)         │  右栏 (flex:1)                    │
│  bg: #f3f4f6          │  bg: #f3f4f6 (内层)              │
│                       │                                  │
│  ┌──────────────────┐ │  ┌────────────────────────────┐  │
│  │ 证件类型选择     │ │  │                            │  │
│  ├──────────────────┤ │  │      A4 纸预览              │  │
│  │ 上传框 (正面)    │ │  │   (白纸 + 阴影)             │  │
│  │ 缩略图 70% 尺寸  │ │  │   85% 高, 0.707 比例        │  │
│  ├──────────────────┤ │  │                            │  │
│  │ 水印配置 (4行)   │ │  │   "A4 PAPER (210X297MM)"    │  │
│  │ Text             │ │  │                            │  │
│  │ Density          │ │  └────────────────────────────┘  │
│  │ Opacity / Size   │ │                                  │
│  │ Angle / Color    │ │                                  │
│  ├──────────────────┤ │                                  │
│  │ [重置] [导出]    │ │                                  │
│  └──────────────────┘ │                                  │
└───────────────────────┴──────────────────────────────────┘
```

- **左栏 (280px, #f3f4f6)**：类型选择 + 上传框 + 水印配置（4 控件纵向：Text、Density、Opacity/Size、Angle/Color）+ ActionBar（底部贴底，Reset 左 Export 右）
- **右栏 (flex:1)**：A4 纸预览（85% 高度，aspect-ratio 0.707），空白时显示灰色占位框 + "A4 PAPER (210X297MM)" 标签
- **弹窗**：仅裁剪操作（点击上传框 → 选择图片 → 弹窗裁剪 → 确认后关闭回到主页面）
- **预览渲染规则**：
  - 单面模式：图片占 A4 80% 宽 × 50% 高，居中
  - 双面模式：正面占上半、反面占下半，每张占 A4 70% 宽，按 ID 比例 1.586 推导高度
- **页面 padding**：`80px 24px 48px`（与其他工具页一致，避开导航栏）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 单面证件处理（学历证、学位证等） (Priority: P1)

用户打开页面 → 主页下拉选择证件类型 → 输入水印内容 → 点击上传框 → 弹窗裁剪 → 预览 → 导出。

**Why this priority**: 单面是最基础场景，覆盖学历证、学位证等大量单面证件，是 MVP 核心路径。

**Independent Test**: 主页下拉选"学历证" → 点击上传框选图 → 弹窗裁剪确认 → 主页水印区输入文字 → 预览区确认 → 导出下载。

**Acceptance Scenarios**:

1. **Given** 用户打开证件工具页（`/card`），**When** 从主页面的类型下拉框选择"学历证"，
   **Then** 上传区显示 1 个上传框，标注"点击上传学历证照片"；水印配置区和预览区均可见但为空状态。

2. **Given** 已选单面类型，**When** 用户点击上传框并选择一张本地图片，
   **Then** 弹出裁剪弹窗（全屏遮罩层），图片显示在裁剪区域内。

3. **Given** 裁剪弹窗中，**When** 用户在空白处按下鼠标拖动绘制裁剪框后点击"确认裁剪"，
   **Then** 弹窗关闭回到主页面，上传框替换为裁剪后的缩略图（70% 尺寸，可点击重新裁剪）。

4. **Given** 图片已裁剪确认，**When** 用户在主页面的水印输入框输入"仅供XX办理使用"，
   **Then** 预览区实时显示带水印的证件图片。

5. **Given** 水印效果满意，**When** 用户点击左栏底部的"导出图片"按钮，
   **Then** 浏览器下载一张合成水印后的 PNG 图片。

---

### User Story 2 - 双面证件处理（身份证正反面合并到一张图） (Priority: P2)

用户选择"身份证" → 输入水印内容输入框 → 主页显示正反两个上传框 → 分别点击弹窗裁剪 → 正反面**上下合并到一张图**预览 → 导出。

**Why this priority**: 身份证是最常用双面证件，"正反面合并到一张图"是打印场景的核心需求（方便直接打印在一张纸上）。

**Independent Test**: 主页下拉选"身份证" → 点击正面框上传裁剪 → 点击反面框上传裁剪 → 水印区输入文字 → 预览区显示正反面上下合并的带水印大图 → 导出。

**Acceptance Scenarios**:

1. **Given** 用户从主页面类型下拉选"身份证"，**When** 选择完成，
   **Then** 上传区显示两个框："身份证正面（人像面）"和"身份证反面（国徽面）"。

2. **Given** 正面框已裁剪确认（显示缩略图），**When** 用户点击反面框上传并裁剪，
   **Then** 弹窗裁剪流程一致，确认后反面缩略图也显示在上传区。

3. **Given** 正反面均已裁剪，**When** 用户在主页水印输入框输入文字，
   **Then** 预览区显示**正反面上下合并**为一张图的效果，水印同时覆盖正反面。

4. **Given** 合并预览和水印满意，**When** 用户点击"导出图片"，
   **Then** 下载一张正反面上下合并的 PNG 大图，方便直接打印在一张纸上。

---

### Edge Cases

- 未选择证件类型时上传框不可用，显示提示"请先选择证件类型"。
- 上传非图片文件 → 显示"请上传 JPG 或 PNG 格式的图片"，不打开裁剪弹窗。
- 图片过大（>20MB）→ 提示"图片过大，请压缩后上传"。
- 水印输入框为空时导出 → 导出无水印图片（允许），或提示确认"未输入水印文字，是否继续？"。
- 双面模式只上传了一面 → 导出按钮可用，合并图中缺失的一面显示空白占位或提示"仅导出了已上传面"。
- 更换证件类型 → 弹出确认"切换类型将清空已上传的图片，是否继续？"。
- 更换证件类型不操作水印输入 → 水印保持不变。
- 裁剪弹窗取消 → 清空该槽位的原始文件（若该槽位尚无已裁剪图片），关闭弹窗；可通过点击 overlay 空白区域、X 按钮、ESC 键关闭。
- 浏览器不支持 Canvas → 显示降级提示"请使用 Chrome/Edge 浏览器"。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在主页面左栏顶部提供证件类型下拉选择框，预设类型：身份证（双面）、学历证（单面）、学位证（单面）、银行卡（单面）、社保卡（单面）、驾驶证（双面）、护照（单面）、自定义。每种类型预设单面/双面属性。
- **FR-002**: 选择单面类型 MUST 显示 1 个上传框，选择双面类型 MUST 显示 2 个上传框（正面/反面），均直接显示在主页面上。
- **FR-003**: 上传框 MUST 支持点击选择本地图片文件；裁剪后显示的缩略图 MUST 占容器 70% 宽高居中。
- **FR-004**: 点击上传框选择图片后 MUST 弹出裁剪弹窗（全屏遮罩），裁剪区域**不锁定比例**，支持自由绘制。
- **FR-005**: 裁剪弹窗 MUST 支持：
  - 在 canvas 空白处按下鼠标拖动 → 绘制新裁剪框（重置当前框）
  - 拖动四角手柄 → 微调裁剪框大小
  - **不支持**裁剪框内部点击移动
  - 鼠标超出 canvas 边界时仍能继续追踪（window 监听 mousemove/mouseup）
  - 旋转图片（左旋 90°/右旋 90° 两个独立按钮）
  - 重置按钮
  - 滚轮缩放图片显示大小（30%-300%）
- **FR-006**: 裁剪确认后 MUST 关闭弹窗，回到主页面，上传框位置显示裁剪后的缩略图（70% 尺寸，点击可重新裁剪）。
- **FR-007**: 水印配置区 MUST 在主页左栏显示（非弹窗），采用**纵向 4 行布局**：第 1 行文字输入框；第 2 行 Density（密度）滑块（Low..High，控制平铺间距）；第 3 行 Opacity（透明度）滑块 + Size（字号）选择；第 4 行 Angle（倾斜度）选择（-45°~45°） + Color（颜色）选择器。默认值：opacity 0.5、fontSize 20、density 0.7。
- **FR-008**: 修改水印参数 MUST 实时更新预览区效果（200ms debounce）。
- **FR-009**: 预览区 MUST 在主页右栏显示——A4 纸背景（aspect-ratio 0.707，85% 高度），空白时显示灰色占位框 + "A4 PAPER (210X297MM)" 标签。
  - 单面模式：图片占 A4 80% 宽 × 50% 高居中
  - 双面模式：正面占上半、反面占下半，每张占 A4 70% 宽，按 ID 比例 1.586 推导高度
  - 右栏自动撑满剩余空间
- **FR-010**: 双面模式导出 MUST 将正反面上下拼接合并为一张 PNG 图片。
- **FR-011**: 导出 MUST 使用 Canvas API 前端合成水印，不依赖后端服务。
- **FR-012**: 单面导出为 1 张 PNG，双面导出为 1 张正反面合并的 PNG。
- **FR-013**: 系统 MUST 提供"重置"按钮（位于左栏底部），一键清空所有上传图片和水印设置。
- **FR-014**: 所有 UI 文案 MUST 通过 vue-i18n 实现中英文双语。
- **FR-015**: 系统 MUST 作为 `/card` 路由的独立视图组件实现，导航栏标签显示"证件"/"Card"。

### Key Entities

- **CardType**: 证件类型定义，含名称、单面/双面标记、默认裁剪宽高比。
- **UploadSlot**: 上传槽位（单面 1 个，双面 2 个），含原始图片 blob、裁剪后 blob、裁剪参数。
- **CropConfig**: 裁剪参数，含 x、y、width、height、旋转角度。
- **WatermarkConfig**: 水印配置，含文字、透明度、字号、位置模式、倾斜度（angle）、颜色、密集程度（density）。
- **MergedImage**: 双面合并产物——Canvas 将正反面上下拼接 + 水印合成后的最终图片 blob。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户完整流程不超过 7 步（选类型 → 上传 → 裁剪 → 确认 → 设水印 → 预览 → 导出）。
- **SC-002**: 10MB 图片的裁剪和水印合成在 3 秒内完成（桌面 Chrome）。
- **SC-003**: 导出图片分辨率保持裁剪区域原始分辨率，不降低画质。
- **SC-004**: 双面合并图的正反面比例正确，拼接无缝。
- **SC-005**: 页面首次加载（路由懒加载）不超过 2 秒。
- **SC-006**: 所有 UI 文案中英文切换正确，无硬编码遗漏。

## Assumptions

- 图片处理全部在浏览器 Canvas API 中完成，不上传至任何服务器。
- 以桌面端使用为主，不针对移动端做特殊适配。
- 水印字体使用系统默认 sans-serif，不引入 Web 字体。
- 双面合并：正反面按 ID 卡比例 1.586 在 A4 上下半部分居中排列。
- 所有数据仅存浏览器内存，刷新页面后丢失。
